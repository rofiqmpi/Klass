# MPI Klass

Mymensingh Polytechnic Institute student, faculty, and academic operations application built with Kotlin Multiplatform and Jetpack Compose (Material 3).

## Key Features
- **Restored Slate & Cobalt Theme with Home Screen Preserved & Social-App Flat Inner Screens**:
  - **Original Color Palette & Large Legible Typography**: Crisp Slate canvas (`#F8FAFC` Light / `#0B1120` Dark) with edge-to-edge `surfaceContainerLowest` feed surfaces (`#FFFFFF` / `#0B1120`), Cobalt primary (`#2563EB` / `#60A5FA`), Cyan/Teal tertiary (`#0F766E` / `#2DD4BF`), Welcome Screen `#8CB9D9` / `#8E7864` / `#94A3B8` 3D accents, and unified `Hind Siliguri` typography scaled up (`17.5.sp` item titles, `15.sp` subtitles, `24.sp` top titles) for instant readability.
  - **Tactile 3D Primary Action Buttons**: Press-animated 3D extruded action buttons (`WelcomeMinimal3DButton`, `WelcomeMinimal3DIconButton`) preserved for primary CTAs, with flat edge-to-edge lists replacing repetitive boxed cards across inner screens.
  - **Restored Original Home Screen & Stationary Bottom Bar**: Floating `HomeRoutineHeader` featuring a compact profile info section next to the avatar (e.g., `6/1/CST-A`) alongside elevated Profile, Messenger (`MessageBubbleIcon` with unread badge), and Notification (`Res.drawable.notification`) circular action buttons; classic bordered `ClassRoutineTable` with subtle practical lab tinting; and a stationary tactile 3D split `HomeMenuBottomBar` outside the `HorizontalPager` (stays fixed while sliding between Home and Menu) preserving the original `home` and `menu` icons with Cobalt active states and display corner-radius adaptation (`homeShape` / `menuShape`).
  - **Telegram / Facebook / TikTok-Style Inner Screens & Content-Matched Shimmer Skeletons**: Edge-to-edge list rows separated by clean `0.5.dp` inset dividers and `8.dp` tonal section bands (no boxed cards around rows), colorful circular leading badges (`44.dp–50.dp`), borderless pill search bars, bold underlined/pill tabs, consistent header Messenger & Notification circular icon buttons (`HeaderAiNotificationActions`) across inner screens, and Notification-style animated card shimmer skeleton loaders tailored to each screen's layout (replacing circular screen spinners app-wide).
- **Screen-Level Language Split**: **Welcome Screen** operates in Bengali (default), while **all inner screens** run strictly in **English** with an instant offline English dictionary in `AppStrings`.
- **Welcome & Role Authentication**: Google Sign-In and email/role flows for Student, Teacher, Admin, and Guest Mode.
- **Teacher Onboarding & Scheduling Preferences**:
  - Teachers configure their **Preferred Class Time Slot** (`Early Periods`, `Late Periods`, or `Any Time`), **Department** (`CST`, `CT`, `ET`, `MT`, `PT`, `ENT`, `EMT`, or `Non-Tech`), **Shift**, and **Semester-wise Multiple Subjects (Semesters 1–7)** selected from the Books Library.
  - Triggered automatically upon Teacher login if setup is not yet complete, and editable anytime from Teacher Profile or Menu.
- **Classroom & Lab Management (Admin CRUD + Bulk Reset & Schedule Viewer)**:
  - Manage Theory Classrooms and Labs (`Add`, `Edit`, `Single Delete`, and `Delete All & Fresh Entry`) with room number, building/floor, type (`Theory` / `Lab`), assigned department (`ALL` or specific department), shift availability (`1st Shift`, `2nd Shift`), and capacity.
  - All roles can inspect individual Classroom & Lab weekly routines and free/occupied periods.
- **Automated 6-Month Constraint-Based Routine Engine**:
  - Supports **5 working days/week** (`Sunday`–`Thursday`; Friday & Saturday off, no half/short classes).
  - **Group Rules**: `CT` and `ET` have **3 groups** (`Group A`, `Group B`, `Group C`); all other 5 departments (`CST`, `MT`, `PT`, `ENT`, `EMT`) have **2 groups** (`Group A`, `Group B`).
  - Admin configures **Shift 1 Start Time**, **Shift 2 Start Time**, **Period Duration (minutes)**, **Periods Per Day**, and **Running Semesters (1–7)** before generating.
  - **Hard Constraints**: Zero teacher overlap per `(shift, day, period)`, zero room/lab overlap per `(shift, day, period)`, and **Single-Teacher-per-Group-Subject Lock** (never splits one group's subject across multiple teachers). Matches labs to Lab rooms, spreads Theory/Practical evenly across days, respects teacher time preferences, and reports any teacher/room shortage conflicts.
  - **Draft, Manual Slot Edit & Admin Approval Workflow**: Generated routines start as **Draft** for conflict review, live clash-checked manual editing/swapping, and **Approve & Publish**. Teachers can submit **Edit/Swap Requests** requiring Admin approval.
- **Personalized Routine Views & Real Automatic Android Push Notifications**:
  - **Student Home**: Displays published routine filtered by student's Department, Shift, Semester, and Group.
  - **Teacher Home**: Extracts and displays all classes assigned to the signed-in teacher across all departments, semesters, groups, and rooms, with a button to request slot/room changes.
  - **Classroom Routine Viewer**: Inspect weekly occupancy for any room or lab.
  - **Real Local Android Push Notifications (Zero Firestore Storage)**:
    - Immediately sends an Android heads-up welcome push notification when logging in / entering from Welcome Screen (`POST_NOTIFICATIONS` runtime permission flow on Android 13+).
    - Automatically schedules recurring weekly per-class push alarms via `AlarmManager` + `BroadcastReceiver` (advance reminder before class + class start alert) matched to each user's live weekly schedule, with automatic `+7d` rescheduling and `BOOT_COMPLETED` recovery—stored strictly on-device with zero Firestore notification writes.
- **Blood Donor Finder (Available in Everyone's Menu)**:
  - Accessible from Admin, Teacher, Student, and Guest Menus; searches institute members who registered their Blood Group, with blood-group filter chips (`A+`..`AB-`), department/address search, and zero-permission `ACTION_DIAL` call launcher.
- **Home & Menu Navigation**: Synchronized `HorizontalPager` sliding across Home and Menu screens with stationary tactile 3D bottom bar and direct tap actions on header controls.
- **Menu-Hosted Account Controls**: Sign Out and Delete Account actions live cleanly in the Menu screen's Account section (`Account` for signed-in roles; `Sign In` for Guests) rather than cluttering the Profile view.
- **Transparent Top-to-Bottom Fading Headers & Top-Right Save Actions**: All screen headers (`GoogleTopAppBar`, `MinimalFullScreenSheet`, Profile overlay, and Edit Profile) use top-to-bottom transparent vertical fading gradients without hard bottom dividers (`statusBarColor` transparent edge-to-edge), and form/editor sub-screens place compact Save/Done actions in the top-right header instead of oversized bottom 3D bars.
- **Facebook-Style Read-Only Profile View & Per-Field Edit Profile**:
  - **Profile Screen (Strictly Read-Only)**: Edge-to-edge status-bar-inclusive cover photo beneath a transparent fading header (`Back` on left; `Edit`, `Find People`, and `Notification` with unread dot on right), rounded `22.dp` top sheet shoulder, centered shadow-free circular avatar (`140.dp`) with thick surface border, centered Display Name + verified badge, role/category subtitle, live Connections count, centered Bio, overlapping mutual connection avatars strip, dual action pills (`Edit profile` + `Connections` / `Messages` on own profile; friend request state + `Message` when viewing another person's profile), filter pills (`All`, `About`, `Connections`) where **`All` displays all visible profile details** (`Academic`, `Contact`, `Personal`, `Teaching Subjects`, and `Connections`) directly without truncation, and zero inline editing (all edits routed strictly to `Edit profile`).
  - **Edit Profile Screen & Per-Field Privacy**: Clean Facebook-style editor (with `Pinned details` removed) featuring per-field visibility controls (**Public**, **Connections**, **Private**) stored per user in `fieldPrivacy` and synced with SharedPreferences & Firestore, updating both from row privacy badges and single-field/picker editors.
- **Unified Messenger Hub (1-on-1 Chat with Zed AI & Campus Peers) & Zero-Retention Direct Messaging (Spark Free Plan)**:
  - **Unified Messenger Entry**: Header Messages button (`MessageBubbleIcon` with unread badge) opens a Messenger-style 1-on-1 chat hub where **Zed AI** is pinned at the top alongside campus peers and active local conversations.
  - **Directory, Peer Chat & Friend Requests**: Discover MPI students, teachers, and admins across Firestore directories (`users`, `students`, `teachers`, `admins`), view privacy-filtered Facebook-style profiles, message peers 1-on-1, and send/accept/decline/cancel requests via the `connections` collection with optimistic UI updates and offline cache persistence.
  - **Zero-Retention Chat Relay**: Real-time direct messages are persisted locally on each participant's device (`chat_history`) while Firestore's `chat_relay` collection acts strictly as a transient delivery relay—incoming messages are appended locally and immediately deleted from Firestore so cloud chat storage returns to zero documents.
- **Admin Teachers Directory & Books Library (179 Official BTEB Probidhan-2022 Books)**: Complete CRUD backed by Firebase Firestore and SharedPreferences cache.
- **Cloud Persistence**: Firebase Auth & Firestore synchronization (`students`, `teachers`, `admins`, `users`, `books`, `classrooms`, `routines`, `routine_edit_requests`, `connections`, `chat_relay`, `config`) with SharedPreferences offline cache.

## Architecture
- `app/`: Android application entry point, Manifest, icons, and launcher setup.
- `shared/src/commonMain/kotlin/com/mpi/klass/`: Shared Compose UI screens (`WelcomeScreen`, `RoleHomeScreen`, `GuestHomeScreen`, `ProfileScreen`, `EditProfileScreen`, `ConnectionsAndChatScreen`, `TeacherPreferencesScreen`, `ClassroomManagementScreen`, `RoutineGeneratorScreen`, `BloodFinderScreen`, `ClassRoutineTable`, `TeachersDirectoryScreen`, `BooksLibraryScreen`, `NotificationScreen`, `AiAssistantScreen`), social/chat repository declarations (`SocialConnectionsManager`), pure Kotlin scheduler (`RoutineGeneratorEngine`), official BTEB curriculum (`BtebBooksCatalog`), Google Material 3 UI primitives (`UiPolishComponents`), localization (`AppStrings`), dialer expect declarations (`PhoneDialer`), and `RoleConfig`.
- `shared/src/commonMain/kotlin/com/mpi/klass/theme/`: Google Material 3 tonal `Color.kt`, `Theme.kt`, typography, system bar theming, and custom Material-style `VectorIcons.kt`.
- `shared/src/androidMain/kotlin/com/mpi/klass/`: Android platform implementations (Firestore repositories, `connections` + zero-retention `chat_relay` sync, local JSON chat history, batch sync, `ACTION_DIAL` phone dialer, photo/date pickers, GPS location, toast helpers).
- `firestore.rules`: Authenticated zero-trust security rules covering all app collections including `connections` and `chat_relay`.
- `firebase-blueprint.json`: Structured schema blueprint for all Firestore entities and collections.
